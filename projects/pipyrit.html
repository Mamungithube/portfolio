Pipyrit Backend

Enterprise-Grade Django REST API for US Immigration Preparation (USCIS / EOIR)

View on GitHub

Project Overview

Pipyrit Backend is a production-ready, enterprise-grade Django REST API platform powering mobile and web applications designed for US immigration preparation (USCIS / EOIR). It transforms daunting legal processes into an intuitive "Guided Interview Flow" with dynamic AI question generation and audio guidelines.

I architected and enhanced the entire backend ecosystem — featuring dynamic OpenAI GPT-4o-mini 25-question interview simulations, Celery & Redis asynchronous audio/email queues, HTTP Range Request video streaming, multi-language translation support (English, Spanish, Haitian Creole), AWS S3 media storage, Firebase push notifications, and dedicated health-check monitoring APIs.

Modular App Architecture & Key Features

AI Quiz & Interview Simulation (quizzes App)

Powered by ai_engine.py integrating OpenAI GPT-4o-mini for dynamic 25-question interview simulations, automated gTTS audio clip generation, and multi-language translations (English, Spanish, Haitian Creole via django-modeltranslation).

Asynchronous Task Engine (Celery + Redis)

Offloaded heavy gTTS audio processing, OpenAI API calls, and Email OTP verification dispatches to background Celery workers backed by a Redis task broker for optimal API responsiveness.

HTTP Range Video Streaming (content App)

Native HTTP Range Request video streaming engine allowing mobile app users to seek and skip through immigration guide videos instantly with zero buffering overhead.

Secure Auth & User Management (user App)

SimpleJWT authentication with Refresh Token Rotation, Email OTP verification, in-app notifications, and Firebase Cloud Messaging (FCM) integration for instant mobile push alerts.

Payment, Subscriptions & Admin KPI (payment / core)

Stripe API integration with automated Webhook listeners, subscription package management, and a centralized Admin Dashboard with real-time KPI analytics and monthly earnings charts.

Enterprise Architecture & Optimization Highlights

Health Check & System Monitoring API (/api/health/)

Built a dedicated public health monitoring endpoint inspecting real-time connectivity for PostgreSQL database, Redis/Celery queue, and OpenAI API status with standardized JSON response envelopes.

AWS S3 / Cloudflare R2 Cloud Storage Integration

Configured django-storages and boto3 for hosting media files and audio clips seamlessly on AWS S3 / R2 buckets when production environment flags are enabled.

Automated DRF Integration Test Suite

Comprehensive test suite covering User Registration, OTP verification, JWT login lifecycle, AI quiz generation, case creation, and Stripe payment webhooks.

Multi-Container Production Dockerization

Docker Compose orchestration featuring Django/Gunicorn, Celery Workers, Redis broker, PostgreSQL database, and Nginx reverse proxy.
