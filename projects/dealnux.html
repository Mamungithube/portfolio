Project Overview

DEALNUX is a scalable, production-ready RESTful API backend platform engineered with Python 3.12, Django 5.x, Django REST Framework (DRF), PostgreSQL 16, Redis, and Celery. It features a multi-channel payment engine (Apple Direct StoreKit 2 IAP, Stripe Connect, and Internal Digital Wallet System), multi-vendor marketplace management, and real-time background task orchestration.

🚀 Key Highlights & Architectural Features

1. Multi-Channel Payment & Subscription Engine

Direct Apple In-App Purchase (StoreKit 2):

Engineered a custom, keyless X.509 certificate chain (x5c) verification system to validate Apple JWS transactions and App Store Server Notifications V2 without third-party dependencies (e.g., RevenueCat) or private keys (.p8).

Stripe & Stripe Connect Integration:

Full support for multi-vendor payouts, Express onboarding, Stripe Payment Intents, and automated webhooks for Web & Android users.

Internal Digital Wallet System:

Integrated balance deduction and instant checkout capabilities for seamless marketplace transactions.

2. Multi-Vendor E-Commerce Marketplace

• Support for physical products, seller stores, coupon engines, multi-item cart calculation, automatic shipping fee logic, and platform commission distribution.
• Automated Seller Payouts: Role-based payout request, review, approval, and automated Stripe Transfer workflows.

3. Background Job Orchestration & Scraper Engine

• Celery & Celery Beat: Scheduled price-tracking alerts, daily usage resets, email notifications, and automated product data scraping (integrated with Scrapy & Walmart API).
• Redis Caching: High-throughput caching for product listings, click tracking, and rate-limiting.

4. Enterprise Security & Administration

• JWT Authentication & RBAC: Customized User Model, Superusers, Managers, and Admin Associate permission layers.
• Django Unfold Modern Admin Panel: Bespoke admin dashboard with financial record protection, customized tabular forms, and quick actions.
• API Documentation: Interactive OpenAPI 3.0 / Swagger UI documentation via drf-spectacular.
