Dealnux Backend Engine

Multi-Platform E-Commerce Price Aggregator & Seller Marketplace Engine

View on GitHub

Project Overview

Dealnux Backend Engine is a high-performance multi-platform e-commerce price aggregator and seller marketplace platform. It synchronizes real-time product pricing from global marketplaces (Amazon, eBay, Walmart) via Celery workers and scrapers/APIs, performing strict NLP token similarity and GTIN/ASIN matching to surface true best deals.

Alongside multi-platform aggregation, Dealnux powers a full local seller marketplace featuring Stripe Connect payouts, an Escrow Wallet System (holding buyer funds until order delivery confirmation), Cost-Per-Click (CPC) seller advertising with automated budget deductions, 11-step KYC seller verification, and DRF scoped rate limiting.

Architecture & Core Modules

Multi-Platform Price Aggregator (store & api_integration)

Real-time price synchronization across 10+ e-commerce platforms using Celery & Redis. Products are matched using Strict NLP token similarity algorithms and GTIN/ASIN canonical mapping.

Escrow Wallet System & Stripe Connect (payment)

Secures buyer funds in escrow upon checkout, automatically deducting a 5–10% platform service fee, and transferring net payouts to sellers via Stripe Connect upon confirmed delivery.

CPC Advertising Engine (custom_ads)

Cost-Per-Click (CPC) ad campaign system for sellers. Tracks valid buyer clicks, deducts ad budget in real-time, and automatically deactivates campaigns when budget reaches zero.

11-Step Seller KYC Onboarding (account)

Multi-stage seller verification workflow requiring business licenses, tax ID verification, and utility bill documentation before granting marketplace selling privileges.

DRF Scoped Rate Limiting & Health Monitoring

Protected price comparison endpoints against scraping abuse using DRF ScopedRateThrottle (anon_search: 30/min, user_search: 100/min), coupled with a centralized /api/v1/health/ health-check API.

Technical Architecture & Optimization Highlights

Centralized System Health Check API (/api/v1/health/)

Built a system monitoring endpoint evaluating connectivity, latencies, and health status for PostgreSQL, Redis, Celery workers, and Elasticsearch clusters.

DRF Scoped Rate-Limiting & Anti-Scraping

Applied strict API throttling policies on product search and comparison endpoints to shield external price fetching workers from DDoS and bot abuse.

Escrow Wallet & Automated Fee Deduction

Engineered transaction ledger holding buyer payments safely until delivery confirmation, calculating platform commission (5-10%) before triggering Stripe Connect payouts.

GitHub Actions CI/CD Pipeline

Configured automated testing and linting workflow (.github/workflows/ci.yml) running Flake8/Ruff, Django unit tests, and Docker container verification on pull requests.
