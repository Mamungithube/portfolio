Pipyrit AI Immigration

AI-Powered Assistant for complex immigration forms (USCIS/EOIR)

View on GitHub

Project Overview

Pipyrit is a modern immigration assistant platform that simplifies complex legal processes (USCIS/EOIR) for everyday people. The core goal of this platform is to transform large immigration forms into a "Guided Interview Flow," where users are asked step-by-step questions in simple language and provided with accurate AI-driven guidelines.

I built the entire backend architecture for this platform — from a dynamic conditional interview engine to automated text-to-speech conversion, secure authentication, and scalable video streaming.

Key Features

Guided Interview Engine

A dynamic interview system using conditional logic. Subsequent questions are determined based on previous answers, making form-filling incredibly intuitive.

AI Audio Automation (gTTS)

Integrated Google Text-to-Speech (gTTS) for quizzes and interviews. When an admin saves a question, the backend automatically converts it to an audio file for the "Listen" feature.

Professional Video Streaming

Implemented HTTP Range Request-based video streaming for the "Smart Frames" section. Users can seek/skip without buffering — far superior to simple file serving.

Centralized Admin Dashboard

A full-control panel for admins featuring real-time business analytics, monthly earnings bar charts, and complete user management in one place.

Secure Auth & IAP Ready

Multi-step authentication flow (Registration → OTP → Activation). Token-based password recovery and a subscription module ready for In-App Purchase (IAP) verification.

How It Works

1

User Starts an Interview

User selects an immigration form and begins the guided flow. The backend serves initial questions.

2

Conditional Logic Engine

Based on user answers, the system dynamically determines the next set of questions. All responses are validated and saved to PostgreSQL.

3

Text-to-Speech Automation

When an admin adds a new quiz, gTTS auto-generates audio, stores the file link, and makes it available via API to the mobile app.

4

Video Streaming with Range Requests

The app requests specific byte ranges of a video file. The backend serves only that portion, enabling smooth seeking and reduced bandwidth usage.

5

Admin Analytics & Subscription

Admins track earnings and user metrics on the dashboard. In-app purchases are verified via Stripe / RevenueCat webhooks.
