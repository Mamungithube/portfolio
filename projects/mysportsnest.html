MySportsNest Backend

Personalized Multi-Sports Feed, Real-Time WebSockets Live Scores & Web Scraping Data Engine

View on GitHub

Project Overview

MySportsNest is a high-performance, containerized multi-sports platform backend engineered to aggregate real-time sports data, live scores, team rosters, player statistics, and news feeds across multiple sports disciplines.

Powered by Django 5.2 and Django Channels with Uvicorn ASGI, the system delivers real-time score broadcasts over WebSockets, executes scheduled background scraping and RSS feed parsing via Celery & Celery Beat, and secures transactions with Simple JWT & CORS.

Technical Architecture Stack

1. Core Framework & APIs

• Python (Virtualenv) & Django 5.2 — Core robust backend architecture.
• Django REST Framework (DRF) — High-speed RESTful API endpoints.
• Django Channels + WebSockets (Uvicorn ASGI) — Real-time live score updates & instant data notifications.

2. Database & Caching

• PostgreSQL 15 (psycopg3 & psycopg2) — Primary relational database for user nests, teams, and match statistics.
• Redis 7 + django-redis — Advanced memory caching, API rate-limiting, and Celery / WebSockets message broker.

3. Background Tasks & Async Workers

• Celery 5.6 — Asynchronous worker processing for high-volume background tasks.
• django-celery-beat — Cron-based periodic task scheduling for automated score & news ingestion.
• Flower — Live monitoring dashboard for Celery tasks and worker node health.

4. Authentication & Security

• Simple JWT (djangorestframework-simplejwt) — Secure token-based authentication.
• django-allauth + dj-rest-auth — User registration, login management, and social authentication.
• django-cors-headers — Strict Cross-Origin Resource Sharing security enforcement.

5. API Documentation

• drf-spectacular — Automated OpenAPI 3.0 schema generation with interactive Swagger UI and Redoc API documentation.

6. Cloud Services & Integrations

• Firebase Admin SDK — Real-time mobile & web push notification dispatch.
• Google Cloud Storage (GCS) — Media assets and sports image cloud storage.
• Resend API — High-deliverability transactional email service.

7. Web Scraping & Data Processing

• BeautifulSoup4, lxml, feedparser — RSS feed parsing & sports content scraping.
• Trafilatura, readability-lxml, googlenewsdecoder — Article lead content extraction and Google News URL decoding.

8. Deployment & DevOps Stack

• Docker & Docker Compose — Multi-container orchestrated pipeline (api, celery, celery_beat, flower, db, redis, nginx).
• Nginx — Reverse proxy with SSL termination (Let's Encrypt / Certbot) and static file serving.
• Gunicorn / Uvicorn & WhiteNoise — Production WSGI/ASGI servers and static asset handling.
