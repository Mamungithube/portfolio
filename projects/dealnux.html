DEALNUX Backend Platform

Multi-Vendor Marketplace & Subscription SaaS Platform with Custom Apple StoreKit 2 Verification

Visit Live Website (dealnux.shop) View on GitHub

Executive Summary

DEALNUX is an enterprise-grade RESTful API backend platform engineered with Python 3.12, Django 5.x, Django REST Framework (DRF), PostgreSQL 16, Redis, and Celery. Designed to power both a multi-vendor marketplace and a subscription-based SaaS model, the platform manages complex multi-channel payments, real-time webhooks, seller payout automation, and background web scrapers.

As the Lead Backend Developer, I architected a zero-dependency Apple StoreKit 2 verification engine, integrated Stripe Connect for automated vendor payouts, designed an internal digital wallet ledger, and implemented automated web scraping pipelines using Celery Beat and Scrapy.

Key Architectural Pillars

Multi-Channel Payment & Subscription Engine

Built a versatile payment ecosystem supporting iOS, Android, and Web subscribers:

  • Direct Apple StoreKit 2 Verification: Engineered a custom, keyless X.509 certificate chain (x5c) verification engine to validate Apple JWS transactions and App Store Server Notifications V2 without third-party SaaS wrappers (RevenueCat) or private keys (.p8).
  • Stripe & Stripe Connect: Integrated Express vendor onboarding, Stripe Payment Intents, subscription webhooks, and automated seller balance payouts.
  • Internal Digital Wallet Ledger: Created a digital wallet system for instant balance deduction, promotional credits, and zero-fee buyer checkout.

Multi-Vendor Marketplace Infrastructure

Scalable e-commerce engine catering to physical products, digital items, and store owners:

  • Multi-item cart calculations, dynamic shipping rules, coupon promotion engines, and automated platform commission splitting.
  • Automated seller payout workflow featuring role-based payout requests, admin reviews, approval pipelines, and Stripe Transfer executions.

Async Task Orchestration & Web Scraper Engine

High-performance background processing powered by Celery, Celery Beat, and Redis:

  • Automated price-tracking alerts, daily quota resets, transaction emails, and asynchronous product data scraping (integrated with Scrapy & Walmart API).
  • High-throughput Redis caching layer for product listings, click tracking, and request rate-limiting.

Enterprise Security & Custom Admin Panel

Fine-grained access control and administration UI:

  • Custom User Model with JWT authentication and multi-tier Role-Based Access Control (Superuser, Store Manager, Admin Associate).
  • Customized Django Unfold Admin Panel providing protected financial record views, inline tabular forms, and quick approval actions.
  • Interactive OpenAPI 3.0 / Swagger UI documentation generated via drf-spectacular.
