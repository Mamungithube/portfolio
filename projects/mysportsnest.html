MySportsNest Backend

Personalized Multi-Sports Feed, AI Entity Deduplication & Data Aggregation Engine

View on GitHub

Project Overview

MySportsNest is a high-performance, personalized multi-sports platform backend designed to aggregate real-time sports data, live scores, team rosters, player profiles, and news feeds from a wide array of third-party sports APIs and RSS feeds.

The platform solves core backend challenges in multi-sport aggregation: handling stringent API rate limits via Redis caching strategies, resolving entity name discrepancies using OpenAI Vector Embeddings and Fuzzy Matching, and parsing background RSS feeds asynchronously with Celery Beat.

Key Features

Multi-Sport API Aggregation & Caching

Aggregates data from API-Sports (Soccer), BallDontLie (NBA), API-Cricket, and TheSportsDB. Custom Redis caching policies with TTL management prevent rate-limit bottlenecks and reduce external API overhead.

AI-Powered Entity Deduplication & Semantic Search

Employs OpenAI Vector Embeddings combined with Fuzzy Matching to map different team/player name variants across sources into canonical entities, enabling intelligent Semantic AI search capabilities.

Automated Background RSS Processing

Scheduled background collection using Celery Beat. Implements URL hash hashing algorithms for fast duplicate article detection and real-time news feed delivery.

Personalized User "Nests" & Feeds

Tailored content feed generator allowing users to follow specific teams, players, and leagues. Includes streak tracking and instant activity notifications.

Production-Ready Containerized Infrastructure

Docker & Docker Compose setup separating web APIs, Celery workers, Celery Beat schedulers, Redis broker, PostgreSQL database, and Flower task monitoring dashboards.

System Architecture & Workflow

1

Data Ingestion & Caching Layer

Requests to external APIs (Soccer, Basketball, Cricket) are routed through a intelligent Redis caching layer with dynamic TTLs based on event status (live vs finished games).

2

AI Entity Normalization

Ingested sports entities (e.g. team names or player aliases) pass through OpenAI Embeddings & Fuzzy Matchers to link duplicates to single canonical entities.

3

Async RSS Ingestion & Hashing

Celery Beat periodically parses RSS news feeds, computes URL hashes for deduplication, and indexes articles under relevant team/league tags.

4

Personalized Feed Dispatch

When a user accesses their personalized "Nest", the backend dynamically synthesizes live scores, recent stats, and news items based on the user's followed entities.
